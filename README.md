38. DEVELOPMENT PROCESS

=======================

Do NOT attempt to build everything blindly in one step.

First:

1. Analyze requirements.

2. Analyze the reference website's functionality.

3. Propose the new information architecture.

4. Propose database architecture.

5. Propose page structure.

6. Propose admin architecture.

7. Propose UI/UX direction.

8. Identify technical risks.

9. Identify required external services.

10. Create implementation phases.

Then implement phase by phase.

After every major phase:

* Run the application.

* Test it.

* Fix errors.

* Check responsive behavior.

* Check browser console.

* Continue only when stable.
